# Kavya Kalavala - AI Engineer Portfolio

A polished personal portfolio website for Kavya Kalavala, focused on AI engineering, machine learning, graph intelligence, topology, and research-driven software systems.

The site presents a cinematic portfolio experience with:

- a hero section and intro story
- selected work case studies
- an interactive lab for graph and topology experiments
- skills, resume, and contact pages
- lightweight 3D and motion-driven UI elements

## Tech Stack

- React 19
- CRACO over Create React App
- React Router
- Tailwind CSS
- Framer Motion
- Radix UI primitives
- Three.js and React Three Fiber
- TanStack Query
